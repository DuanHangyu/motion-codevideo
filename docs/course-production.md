# 一门精品互动课的完整制作过程 · 以 AlexNet 为例

这份文档完整记录了「AlexNet：一次让机器学会“看”的革命」这门课从零到上线的全过程：做了什么、按什么顺序做、每一步产出什么、在哪个文件里、踩过哪些坑。

它有两个用途：

1. **复盘**：说清楚这门精品课是怎么做出来的。
2. **模板**：以后做第二门精品课时，照着第五部分的清单走；做自动化生成平台时，第六部分说明哪些环节可以交给机器、哪些必须保留人工。

> 技术细节（章节表、事实核对、素材许可、命令）见 [alexnet.md](alexnet.md)。本文侧重“过程”。

---

## 一、成品是什么

| 层次 | 内容 | 规模 |
|---|---|---|
| 视频课 | 中文科普视频，面向入门大学生 | 14 分 27 秒，1920×1080 / 30fps，11 个章节，95 句旁白 |
| 互动课堂 | 同一套画面在网页里实时播放，可暂停走进画面 | 10 个画面世界、6 次先猜后看、4 组 16 道测验 |
| 学习系统 | 掌握度、知识图谱、课堂目录、AI 助教 | 34 个大节点 / 133 个知识点；AlexNet 的 10 个知识点已开课 |

核心设计原则只有一条：**视频和互动课堂是同一份代码**。`src/alexnet/Lesson.tsx` 被 Remotion 离线渲染就是 MP4，被网页播放器实时运行就是可交互的课堂。所以互动不是另做一套白板，而是“让时间停住，画面本身变得可操作”。

              │                     │
              └──────────┬──────────┘
                         ▼
                ⑦渲染与逐帧质检 ──► out/alexnet.mp4（视频版完成）
                         │
                         ▼
     ⑧课堂网站：播放器 + 时间轴 + 测验 + 掌握度
                         │
                         ▼
     ⑨互动化：画面世界（暂停即探索）+ 先猜后看

整条流水线只有一个“真相来源”：**剧本文案 → 配音时间轴**。画面动作、字幕、音乐起伏、测验弹出时机、画面世界的开放时间窗，全部按配音说出某个词的时刻来定位。改一句文案，重跑配音，所有东西自动重新对齐。

## 三、分阶段详解

### 阶段 ① 选题与教学设计

**目标**：确定讲什么、讲给谁、用什么思路讲。

- **受众**：刚入门 AI 的大学生，有高中数学基础，没有深度学习背景。
- **核心立意**：不只讲“AlexNet 是什么结构”，而是讲 **“为什么当时的人这样想、这样设计，它带来了什么改变”**。这决定了整门课的叙事方式：每一章都从一个问题出发。
- **叙事骨架**：以 2012 年 ImageNet 比赛的“意外”开场制造悬念，然后倒回去讲清楚一路的难题：
  1. 图片对机器来说是什么？
  2. 人工设计特征为什么走不下去？
  3. 机器怎么学？
  4. 为什么要卷积？
  5. 为什么要 ReLU？
  6. 深度带来了什么？
  7. AlexNet 的整体结构。
  8. 为什么偏偏是 2012 年（数据、算力、正则化三把钥匙）？
  9. 它开启了什么。
  10. 本质的转变是什么。
- **产出**：11 章的章节表（序章 + 01–10），每章写下“核心问题”和“主要视觉”。见 [alexnet.md 的章节表](alexnet.md)。

**经验**：
- 先写“核心问题”，再想画面。每一章只回答一个问题。
- 在关键处设计“停下来想一想”的节点（如卷积章里全连接需要多少参数），这些后来自然变成了测验点和“先猜后看”。

### 阶段 ② 写剧本

**目标**：写出逐句旁白，并结构化成机器可读的格式。

- **文件**：`src/alexnet/script.json`，整门课唯一的文案来源。
- **结构**：
  - 全局参数：`voice`（`zh-CN-XiaoxiaoNeural`）、`rate`（+5%）、`defaultGap`（句间默认停顿 0.45 秒）。
  - 11 个 `scenes`，每个场景有：
    - `id`、`num`、中文和英文标题；
    - `lead` 和 `tail`：章首和章尾的留白秒数；
    - `lines`：逐句旁白，每句有 `id`（如 `p3`）、`text`，以及可选的 `gap`，用来单独加长停顿。
- **写法要求**：口语化、短句、每句一个意思；数字写成“读得出来”的形式（“224乘224”“十五万多个”）；重点前留停顿。

**示例**（第 01 章片段）：

```json
{ "id": "p4", "text": "一张224乘224的小小彩色照片，就是十五万多个数字。", "gap": 0.9 },
{ "id": "p5", "text": "更麻烦的是，同一只猫，只要往旁边挪动几个像素，就有七成的数字发生了变化。" }
```

**事实核对**同步进行：比赛成绩、论文参数、GPU 型号、训练时长、参数量等，全部核对原始出处，并记录在 [alexnet.md 的事实核对](alexnet.md)。画面里出现的每个数字都要能追溯来源。

**经验**：
- 句子 `id` 要稳定，后面所有画面和交互都靠它定位（`cue("p5", "七成")`）。
- 文案里每个“具体的说法”（七成、91.4%、2048 倍）都必须有真实数据或出处支撑，不能拍脑袋。

### 阶段 ③ 用真实模型取素材

**目标**：让“网络学到了什么”的画面全部来自真实的预训练 AlexNet，而不是示意图。

- **文件**：`ml/extract.py`，运行 `npm run alexnet:data`。
- **输入**：一张猫的照片（CC0 授权，存于 `data/alexnet/`）。
- **处理**：用 torchvision 的预训练 AlexNet 跑一遍，导出：

| 素材 | 用途（章节） |
|---|---|
| `cat.jpg` / `cat224.png`、像素网格 | 01 像素、3D 高度场 |
| `shift_diff.png` | 01 平移几个像素后有多少数字改变（得出“七成”，即 70.7%） |
| `hog.png` | 02 手工特征 HOG |
| `edges.png` | 04 一个手选卷积核（Sobel）看到的边缘 |
| `filters.png` | 06 第一层真实卷积核 |
| `fmap_conv1…5.png` | 06/07 各层真实特征图 |
| `gradcam.png` | 07 网络在看哪里（Grad-CAM） |
| `data.json` | 预测结果（91.4% 虎斑猫）等数值 |

- **输出位置**：`public/alexnet/`，视频和网页共用。

**经验**：
- 真实数据是这门课“可信、震撼”的关键。学生看到的是真的卷积核、真的特征图。
- 教学用的 2012 原版（双 GPU、96 个卷积核）和 torchvision 版本（单 GPU、64 个卷积核）有差别，要在画面里如实注明。

### 阶段 ④ 配音与时间轴

**目标**：合成配音，并得到精确到每个字的时间轴。这是整条流水线的心脏。

- **文件**：`audio/alexnet/tts.py`，运行 `npm run alexnet:voice`。
- **做法**：
  1. 用 Microsoft Edge TTS（晓晓）逐句合成，同时拿到每个词的边界时间（WordBoundary）。
  2. 把词对齐回原文的字符位置。
  3. 按 `lead`、`gap`、`tail` 拼出全片的绝对时间轴。
  4. 按文本哈希缓存：只重新合成改过的句子。
- **输出**：
  - `public/alexnet/vo/<句子id>.mp3`：每句一个音频文件。
  - `src/alexnet/generated/timeline.json`：每个场景、每句、每个字的起止时间。
- **画面如何使用时间轴**：`src/alexnet/lib/timeline.ts` 提供：
  - `cue("c9", "滑动")`：配音说出“滑动”的那一刻；
  - `lineEnd("c15")`：这句结束的时刻；
  - `scene("conv")`：这一章的起止时间。

**经验**：
- “画面跟着配音走”，而不是“配音去对画面”。这样改文案的成本极低。
- 字幕也直接从时间轴生成，逐字高亮，不需要人工打轴。

### 阶段 ⑤ 画面场景制作

**目标**：为每一章做出大量 2D/3D 动画，每个动作卡在配音的关键词上。

- **技术**：Remotion（React 写视频）+ Three.js / React Three Fiber（3D）+ 后期辉光（Bloom）。
- **文件组织**：
  - `src/alexnet/Lesson.tsx`：总入口，按时间切换章节，叠加章节轨、字幕、章节卡。
  - `src/alexnet/scenes/*.tsx`：每章一个文件，部分大章拆成多个文件。
    - 01–02 章：`Open`（序章）、`Pixels`、`Hand`。
    - 03–05 章：`Neuron`、`Conv`、`Hubel`、`ConvSlide`、`Relu`。
    - 06–10 章：`Hier`、`Arch`、`Keys`、`Impact`、`Legacy`。
  - `src/alexnet/components/`：可复用组件。
    - `Stage3D`：3D 舞台。
    - `ParticleText`：粒子文字。
    - `Subtitles`：字幕。
    - `ChapterCard`：章节卡。
    - `ui`：标题、正文、面板等。
  - `src/alexnet/lib/`：
    - `theme.ts`：配色，一种颜色对应一种概念，全片一致。
    - `anim.ts`：缓动、渐入等动画函数。
    - `arch.ts`：网络结构数据。
    - `convolve.ts`：卷积的纯函数计算。
    - `loss.ts`：损失地形。
- **关键原则：确定性**。每一帧的画面都只由时间 `t` 决定（`t → 画面` 的纯函数），不依赖随机数和墙上时钟。这样才能并行渲染，也才能在网页里随意跳转、和视频逐帧一致。
- **视觉语言**：
  - 深色“夜间实验室”风格。
  - 一种颜色表示一种概念：琥珀色 = 卷积/权重，青色 = 输入/数据，紫色 = 全连接，青柠色 = 正确/激活，珊瑚红 = 误差。
  - 3D 用于表现空间和结构，例如像素高度场、损失山地、3D 网络。
  - 2D 用于表现数字和对比，例如成绩榜、曲线、参数量。

**经验**：
- 每个场景都按“这句话说到哪个词，画面做什么”来写。
- 3D 场景的镜头也用时间函数控制，做到推、拉、环绕都可复现。
- 大量使用真实素材贴图（3D 网络各层表面贴真实特征图），让抽象结构“看得见”。

### 阶段 ⑥ 配乐、音效与混音

**目标**：不用任何采样，全部程序合成音乐和音效，并与画面精确同步。

- **文件**：`audio/alexnet/score.py`，运行 `npm run alexnet:score`。
- **内容**：
  - **乐器合成**：pad 和弦、钟声、低音、鼓、hi-hat。
  - **音效**：whoosh、riser、impact、blip、时钟滴答、zap、shimmer。
  - **章节情绪**：每章一组和弦进行，例如序章悬疑、ReLU 章明亮、结尾宏大。
  - **自动化**：说话时音乐自动下沉（ducking）。“想一想”暂停时，音乐几乎消失，只留时钟滴答。
  - **音效挂点**：每个音效都用和画面相同的 `cue()` 挂在关键词上，比如章节卡出现时的“一口气 + 低音撞击”，成绩揭晓时的 impact。
  - **混音**：人声 + 音乐 + 音效，响度标准化到 -16 LUFS。
- **输出**：`public/alexnet/mix.wav`（渲染用）和 `mix.m4a`（网页用）。

### 阶段 ⑦ 渲染与质检

- **抽帧检查**：`npm run alexnet:stills -- out/stills/x 120 300 …`，按秒截图并拼成一张对照图，逐章检查遮挡、错位、文字溢出。这是最常用的质检手段。
- **预览**：`npm run alexnet:studio`，可在 Remotion Studio 里逐帧拖动查看。
- **成片**：`npm run alexnet:render`。Remotion 并行渲染出无声视频，再用 ffmpeg 合入混音，得到 `out/alexnet.mp4`。
- **常见问题**：
  - 贴图还没加载完就渲染，导致个别帧缺贴图。修法是等贴图加载完成后再挂载 3D 场景。
  - 文字压住主体画面，或字幕遮挡重要内容。
  - 数字和画面不一致：先回到第 ③ 步检查数据，不在画面里手改数字。

**到这里，视频版就完成了。**

### 阶段 ⑧ 课堂网站（第一版 MVP）

**目标**：把视频变成一个可学习的课堂，而不只是观看。

- **技术**：Vite + React，`@remotion/player` 在网页里实时播放 `Lesson` 组件（不播放 MP4）。
- **页面**：首页（输入学习目标）→ 知识图谱 → 课堂页 → 测验。
- **课堂页**：
  - 播放器；
  - 时间轴：按章节分段，并标出画面世界、先猜后看、测验点；
  - 侧栏：本课 10 个知识节点及掌握度。
- **测验**：`classroom/quiz/questions.ts` 中有 16 道题，分 4 组弹出。
  - 卷积章末、ReLU 章末、全貌章末各一组小测，课程结尾一组结课测验。
  - 弹出时机由 `classroom/lesson/zones.ts` 用 `lineEnd()` 定位。
  - 题型有单选、判断和“预测特征图”。
  - 答错可以“回到该段”或“走进画面再探索”。
- **掌握度**：`classroom/progress/mastery.ts` 是纯函数。看完片段得基础分，答对加分、答错扣分，分为未学习、学习中、待复习、已掌握四档，存在浏览器 localStorage 中。不需要账号或后端。

**这一版的问题**（来自你的体验反馈）：互动太少；没有视觉冲击；暂停后弹出的是独立的“实验台白板”，没有“进入视频世界”的沉浸感。

### 阶段 ⑨ 互动化：暂停即探索（画面世界）

这是整门课最有特色的部分，也是最费心思的一步。

**核心思路：时间冻结。** 学生暂停时，不弹新窗口，**当前画面直接变成可以动手的世界**。离开时，画面从学生改过的状态平滑恢复成剧本状态，然后继续播放。

- **状态机**（`src/alexnet/lib/explore.ts`）：
  - 四个阶段：未进入 → 进入中 → 探索中 → 返回中。
  - 进入和返回都有 0.9 秒的混合系数 `blend`（0 到 1）。
  - 场景里每个可交互的量都写成“剧本值”和“学生值”按 `blend` 插值，所以离开时自然回到原样。
  - 渲染 MP4 时永远不会进入探索态，视频的确定性不受影响。
- **3D 场景**：传入 `zone` 后，进入时镜头推近，然后学生可以拖动旋转；离开时镜头飞回剧本机位。
- **10 个画面世界**（定义在 `src/alexnet/lib/worlds.ts`，时间窗同样用 `cue()` 定位）：

| 画面世界 | 学生能做什么 | 挑战 |
|---|---|---|
| 像素 | 鼠标扫过像素山脉看 RGB；拖动平移、调亮度 | 找到猫的蓝眼睛像素 |
| 神经元 | 拖动权重旋钮、输入、偏置 | 把输出调到 1.50 |
| 梯度下降 | 把小球放到山地任意处，调学习率 | 让小球停在最深的谷底 |
| Hubel 实验 | 旋转、移动光条，听神经元放电声 | 测出方向调谐曲线 |
| 卷积滑动 | 拖动卷积核、编辑权重、扫描整张图 | 造一个找水平边缘的卷积核 |
| 激活函数 | 切换 sigmoid、tanh、ReLU，调层数 | 12 层以上仍保留 90% 信号 |
| 池化 | 编辑格子、平移特征 | 改动 3 个数字，最大池化输出不变 |
| 网络结构 | 3D 中点击任意层看尺寸、参数、特征图 | 找出参数最多的一层（全连接 6） |
| 数据增强 | 裁剪、翻转、调色，一张图变出一批 | 三种方法全开，生成 20 张 |
| Dropout | 调丢弃率，单步或自动训练 | p = 0.5 训练 10 步 |

- **反馈感**：
  - 完成挑战时有和弦、撞击音效和光环。
  - 交互音效用 Web Audio 实时合成（`src/alexnet/lib/sfx.ts`），没有音频文件。
  - 完成挑战计入对应知识点的掌握度。
- **先猜后看**（6 次）：视频讲到关键结论前自动暂停，弹出选择题。学生选完继续播放，讲到答案时角落显示“猜对了”或正确答案。
- **验证**：每个世界都在浏览器里实际操作并完成挑战，逐个检查遮挡问题（任务提示挡住内容、面板压住图表等），并确认视频截帧不变。

**经验**：
- 先做 3 个样板世界给你确认方向，再推广到其余 7 个。这一步避免了大量返工。
- “平滑恢复原样”是沉浸感的关键：学生离开时不能“啪”地跳回去。
- 交互世界必须和视频画面完全是同一个场景，只是“时间停了”。

### 阶段 ⑩ 知识图谱、课堂外壳与风格统一

- **知识图谱演进**（经历了三版，都是根据你的反馈）：
  1. 一层 16 个节点的 3D 地图。问题：AlexNet 的子知识点和 Transformer 这类大节点混在同一层。
  2. **两层结构** + 3D 星系视觉：大节点是恒星，子知识点是行星。
  3. 按你给的参考图改成**浅色 2D 关系图**，并加密到 34 个大节点、133 个知识点、5 条主线：
     - 主线：神经网络基础、视觉、序列与语言、生成与多模态、强化学习。
     - 箭头上写明关系，比如“加深网络”“完全基于”。
     - 悬停时点亮关联，点击大节点展开子知识点。
     - 支持搜索、筛选、缩放。
  - 数据在 `classroom/map/universe.ts`，AlexNet 的 10 个子知识点在 `graph.ts`，绘图在 `KnowledgeGraph.tsx`。
- **视觉风格**：首页、图谱、课堂页统一为浅色的 PolyPilot Learning Space 风格。视频画面本身保持深色，作为课堂里的“屏幕”。
- **课堂目录与 AI 助教**（后续提交）：
  - 课堂左侧加了课程目录。
  - AI 助教面板能针对当前知识点给出解释、生活例子和小测（`classroom/lesson/lessonChat.ts`）。
  - **目前是预设的离线回复，不调用大模型**，接入真实模型是后续工作。

### 阶段 ⑪ 工程化与交付

- **测试**：用 vitest 测试纯函数和数据一致性，最近一次记录为 61 个测试全部通过。覆盖：
  - 卷积和梯度下降的计算；
  - 掌握度规则；
  - 画面世界的时间窗是否有序、是否落在课程内；
  - 每个知识点是否都有测验题；
  - 知识图谱的节点 ID 是否唯一、先修关系是否成环；
  - 助教回复；
  - 子路径部署。
- **清理**：删除第一版的独立实验台和残留样式，保证项目里只有最终版。
- **部署**：`npm run classroom:build` 产出静态站点 `out/classroom/`，可以放在任意子路径下运行，方便作为功能模块嵌入 PolyPilot 平台。
- **版本管理**：每个阶段一个独立提交，在 `feat/classroom-worlds` 分支上。

| 环节 | 工具 | 人工必须把关的部分 |

## 五、做下一门精品课的清单

按顺序执行，每一步都有可检查的产出：

- [ ] **1. 定位**：写一句话立意（“这门课要让学生明白……为什么……”），以及受众画像。
- [ ] **2. 章节表**：8–12 章，每章写“核心问题”和“主要视觉”。
- [ ] **3. 剧本**：写进 `script.json`，句子 id 稳定，口语化，数字写成读法。
- [ ] **4. 事实核对**：每个数字、年份、人名都有出处，记入文档。
- [ ] **5. 真实素材**：如果涉及可计算的东西（模型、算法、数据），先用真实代码跑出素材。
- [ ] **6. 配音**：生成配音和时间轴，通听一遍，修正读音和停顿。
- [ ] **7. 画面**：逐章制作，每个动作用 `cue()` 挂到关键词上。每完成一章就抽帧检查。
- [ ] **8. 音乐音效**：定每章情绪，把音效挂到关键词上，混音到 -16 LUFS。
- [ ] **9. 渲染**：抽帧通检后渲染成片，完整看一遍。
- [ ] **10. 测验**：每章末 3 题左右，结尾一组；每个知识点至少一道题。
- [ ] **11. 先猜后看**：挑 4–6 个“反直觉”的结论，在揭晓前提问。
- [ ] **12. 画面世界**：先做 3 个样板确认方向，再推广。每个世界都要有一个明确的挑战。
- [ ] **13. 知识图谱**：把这门课的知识点挂到图谱的对应大节点下（`graph.ts`、`universe.ts`）。
- [ ] **14. 验证**：在浏览器里走一遍完整学习路径，跑测试，确认视频截帧不变。

## 六、从“一门精品课”到“平台自动生成”

这门课验证了**一个节点的体验上限**，但它的生产方式（每门课都从零写专属代码）又慢又贵，无法规模化。复盘下来，各环节可以这样分工：

| 环节 | 现在 | 平台化后 |
|---|---|---|
| 知识图谱 | 手写 | 大模型生成 JSON，几秒完成 |
| 剧本 | 人和大模型共同打磨 | 大模型按模板生成，结构同 `script.json` |
| 配音、时间轴 | 已自动 | 直接复用 `tts.py` 的做法 |
| 画面 | 每章手写代码 | **从模板库里选场景 + 填参数**（大模型只输出 JSON） |
| 画面世界 | 每个手写 | 模板自带交互（例如“网格算子”模板天然支持拖动卷积核） |
| 测验、先猜后看 | 手写 | 大模型生成，按时间轴自动挂载 |
| 渲染 | 预渲染 MP4 | 浏览器实时播放，不再渲染 |

关键的一步，是**把这门课里做过的场景抽象成通用模板**。例如：
- 像素山脉 → “数据即地形”；
- 卷积滑动 → “网格算子”；
- 梯度下降 → “损失地形”；
- 3D 网络 → “分层管线”。

精品课用来定标杆、沉淀新模板；模板课负责覆盖大量主题。具体方案见此前的平台方案讨论。
